# Face Detection and Recognition System

## About the Project
This project was developed as part of my CodeSoft internship. It uses Python and OpenCV for real-time face detection and basic face recognition through a webcam.

## Features
- Real-time face detection
- Webcam integration
- Basic face recognition using LBPH
- Displays a recognized label or "Unknown"

## Technologies Used
- Python
- OpenCV
- NumPy

## Project Files
- `face_detection.py` – Detects faces using a webcam.
- `face_recognition.py` – Performs basic face recognition using a sample image.

## Note
This is a basic educational project. Recognition accuracy depends on the training image and lighting conditions.
